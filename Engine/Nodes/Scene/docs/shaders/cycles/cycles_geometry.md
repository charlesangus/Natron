# Geometry

Generated from the Cycles shader manifest by `tools/shaders/audit_shader_nodes.py`.

| normal | normal |
| tangent | normal |
| true_normal | normal |

| parametric | point |
| backfacing | float |
| pointiness | float |
| random_per_island | float |
