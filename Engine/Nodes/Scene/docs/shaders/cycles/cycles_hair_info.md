# Hair Info

Cycles utility `cycles_hair_info`, for the cycles target.

Generated from the Cycles shader manifest by `tools/shaders/audit_shader_nodes.py`.

## Outputs

| Name | Type |
| --- | --- |
| is_strand | float |
| intercept | float |
| size | float |
| thickness | float |
| tangent_normal | normal |
| index | float |
