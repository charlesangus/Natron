# Object Info

Cycles utility `cycles_object_info`, for the cycles target.

Generated from the Cycles shader manifest by `tools/shaders/audit_shader_nodes.py`.

## Outputs

| Name | Type |
| --- | --- |
| location | vector |
| color | color |
| alpha | float |
| object_index | float |
| material_index | float |
| random | float |
