# Particle Info

Cycles utility `cycles_particle_info`, for the cycles target.

Generated from the Cycles shader manifest by `tools/shaders/audit_shader_nodes.py`.

## Outputs

| Name | Type |
| --- | --- |
| index | float |
| random | float |
| age | float |
| lifetime | float |
| location | point |
| size | float |
| velocity | vector |
| angular_velocity | vector |
