# Optics resources

Data files for the optics library in `Engine/Optics`, installed to
`Resources/optics/` next to the Natron binary. Licences and sources are in the
`LICENSE-*.txt` files here.

| File | Contents | Generated by |
|---|---|---|
| `glass.json` | Schott, Ohara, Hoya, CDGM, Hikari and Sumita glass catalogues (nd, Vd, dispersion formula) | `tools/optics/convert_glass.py` |
| `lenses.zmx.gz` | 986 of the 1,041 photographic lens prescriptions of OpticsDatabase (see below), read by `Optics::LensDatabase` | `tools/optics/convert_lenses.py` |

Both come from OpticsDatabase (https://github.com/amegahed/OpticsDatabase, MIT)
at the pinned commit `1b007269eda014b9e4d23670d5d5d7dd2dfe6de5`.

## lenses.zmx.gz

Every `Optics/Photography/<Vendor>/**/*.zmx` becomes one lens with the id
`<Vendor>/<file stem>`, cut down to the lines the `.zmx` parser reads (plus
`NOTE`, for attribution) and gzipped. Lenses that fail to parse, have no
paraxial focus or parse differently from their original file are left out with a
warning. At the pinned commit 986 of the 1,041 files are kept: the rest are
teleconverters, close-up lenses, speed boosters and mirror lenses (no stop
surface) and 7 files with malformed numbers.

Natron also lists its built-in prescriptions as the "Classic Designs" vendor;
they are compiled in, not part of the archive.

### Re-running the conversion

From the repository root, with a checkout of OpticsDatabase at the pinned commit
somewhere outside the source tree:

```sh
git clone https://github.com/amegahed/OpticsDatabase <checkout>
git -C <checkout> checkout 1b007269eda014b9e4d23670d5d5d7dd2dfe6de5

g++ -std=c++17 -O1 -I. tools/optics/check_lenses.cpp Engine/Optics/LensDatabase.cpp \
    Engine/Optics/ZemaxParser.cpp Engine/Optics/DatParser.cpp Engine/Optics/Prescription.cpp \
    Engine/Optics/BuiltinLenses.cpp Engine/Optics/Paraxial.cpp Engine/Optics/Glass.cpp -lz -o <tools>/check_lenses

python3 -I tools/optics/convert_lenses.py <checkout> 1b007269eda014b9e4d23670d5d5d7dd2dfe6de5 \
    --checker <tools>/check_lenses
```

The output is deterministic: a rerun on the same checkout gives a byte-identical
archive. To move to a newer OpticsDatabase commit, update `PINNED_COMMIT` in the
converter, this file and `LICENSE-OpticsDatabase.txt`, and rerun. Lens ids are
file names, so a lens renamed upstream gets a new id and projects that saved the
old one show a missing-lens error until it is picked again.
