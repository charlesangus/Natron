# One engine-wide GPU backend

2026-10-09, user-requested via a side-session GPU investigation. The engine gets one GPU compute backend, chosen in M83 - GPU Compute Backend Spike and used by native nodes, the task-graph scheduler and raw kernels alike. There is no separate OpenCL raw path. M80.P6.T1 therefore no longer chooses a backend: it records the raw kernels' requirements for M83. M81 - Raw GPU Kernels waits on M83's decision, and ideally on M84 - GPU Placement And Residency. Vulkan compute with Slang kernels is the leading candidate, pending the user's confirmation in M83. The residency argument holds that one PCIe round trip of a 4K float frame (about 11 ms) costs as much as several CPU point ops, so only connected resident regions pay off. M82 - Render Cost Profiling measures this before any architecture is committed. M68 - Headless GL EGL is kept for OFX GL plugins and is re-scoped when M83 lands.
