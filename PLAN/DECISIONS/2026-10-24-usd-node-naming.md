# USD nodes are named USD<Whatever>

Every node in the USD/3D system (E9 - USD And 3D) is named `USD<Whatever>`, the same prefix convention the deep nodes (`DeepRead`, `DeepMerge`, `DeepToImage`) and raw nodes (`Raw<Whatever>`) use. The user stated the rule while grilling M19 - USD/Hydra Foundation on 2026-10-24. It applies to plug-in IDs, labels, class names and source file names. M19's `ReadScene` becomes `USDRead`. The other E9 milestones (M20 - 3D Node Vocabulary, M52 - USD Layer-Stack Completion, M53 - Projected Texture Painting, M54 - SOPs-Style Geometry) still use the design doc's `*3D`/`*Scene` names (`Camera3D`, `Merge3D`, `WriteScene`, `HydraRender`, …) and are renamed to the `USD` prefix when they are next elaborated or claimed, e.g. `USDCamera`, `USDMerge`, `USDWrite`, `USDRender`.
