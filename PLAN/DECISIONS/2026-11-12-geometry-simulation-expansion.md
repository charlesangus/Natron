# Geometry, simulation and solver expansion

2026-11-12, /cat-plan --grill with the user. Native geometry grows toward Houdini's SOP and POP feature set, and simulation is built on the existing loop and render-context core (`2026-10-25-loops-and-i-nodes-architecture.md`) rather than a separate engine.

- **Loops carry geometry, not scenes.** Loop blocks were image-only, and the scene and geometry pull paths ignored render contexts. Geometry gets its own `GeoForEachBegin`/`GeoForEachEnd` block (statically typed edges), with render contexts mixed into `evaluateGeometry()` and `GeoDetailKey`. Scene (USD stage) edges stay refused.
- **Simulation is a cross-frame geometry block.** `GeoSolverBegin`/`GeoSolverEnd` (the Solver SOP) holds a RAM sim cache that spills to disk in a native paged geometry format, and resets on any edit. Particles are a POP-style `ParticleSolver` block on top of it, with `Pop*` nodes in the body. Collisions use VDB SDFs. A Slang backend for the kernel language lets wrangles run on resident GPU particles. A CPU path is always kept.
- **2D solvers are image-graph nodes.** `Fluid2D` is one node (stable fluids with multigrid pressure, GPU and CPU). Its domain is fixed by format × scale, so proxy and RoI never change the sim. `Fluid2DShade` shades without lighting. 2D particles reuse the POP engine in a 2D mode, and `ParticleRender` draws them, or 3D particles through a camera, to images.
- **Operators are in-house on `GeoDetail`**, so attributes and groups survive. Geometry gains a Bezier primitive and an OpenVDB volume primitive. Volumes reach renderers as content-hashed `.vdb` files.
- **Grouping.** New epic E22 - Simulation And Solvers for loops, solver, particles and 2D fluids, with the operators and VDB under E9 - USD And 3D. Features: F18 - Geometry Loops And Solver, F19 - Particles, F20 - 2D Fluids, F21 - Geometry Operators (including M362 - Geometry Operators II) and F22 - Native VDB. F19 - Particles waits on F22 - Native VDB for collisions. Every geometry Feature waits on F15 - Native Geometry landing.
