# Native geometry is a first-class texture-painting source

2026-11-14. Asked in `/cat-discuss` whether F11 - Texture Painting works on native geometry as well as USD, the user ruled out the `GeoToUSD` route as the answer: "We need native geometry support as a first class member, not via conversion." TexturePaint (M53 - Projected Texture Painting) reads only a composed `UsdStage`, so native geometry needed a `GeoToUSD` node first, and no test covered that path. After weighing one node with a Scene|Geometry input against a split, the user chose the split, in line with the SOP/LOP rule of `2026-09-18-geometry-is-a-fourth-data-kind.md`: `USDTexturePaint` (M53's node, renamed now, before F11's UAT) and `GeoTexturePaint` (M427 - Native Geometry Texture Painting) share one base, with a `GeoDetail` mesh source under SceneRaster. A third node, `GeoAttribPaint` (M429 - GeoAttribPaint Node), ports the Attribute Paint SOP and outputs geometry. Native UV Project, Flatten and Layout come in M428 - Native UV Operators, and a Viewer 2D/3D switch for image nodes with a 3D source in M430 - Viewer 2D/3D Switch. Rendering native geometry still crosses into USD through `GeoToUSD`.
