# Native geometry is a first-class TexturePaint source

2026-11-14. Asked in `/cat-discuss` whether F11 - Texture Painting works on native geometry as well as USD, the user ruled out the `GeoToUSD` route as the answer: "We need native geometry support as a first class member, not via conversion." TexturePaint (M53 - Projected Texture Painting) reads only a composed `UsdStage`, so native geometry needed a `GeoToUSD` node first, and no test covered that path. M427 - Native Geometry Texture Painting lets TexturePaint take the geometry kind directly through a mesh-source interface in SceneRaster with a `GeoDetail` adapter, SOP-style group selection, and a base of `Cd`, else an optional Base image, else empty (user's choice). It amends the explicit-bridge split of `2026-09-18-geometry-is-a-fourth-data-kind.md` for painting only: rendering still crosses into USD through `GeoToUSD`. The user also asked for native UV Project, Flatten and Layout operators (M428 - Native UV Operators), since native geometry had no way to author UVs.
