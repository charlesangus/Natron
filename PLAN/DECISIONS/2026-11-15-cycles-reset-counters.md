# Cycles restarts are detected from reset counters in the fork

Natron tells a Cycles render that restarted for an edit from one still showing the old image by reset counters the Natron Cycles fork now exposes as render stats (`resetsRequested`, `resetsWritten`, `resetsConverged`; fork commit 90d7cb7bd on charlesangus/cycles natron/deep-5.2, pinned in tools/ci/local/Dockerfile). Samples and the render clock could not separate an ordinary edit on an idle session (the fork excludes scene-update time from the clock, so it need not fall) from a reload a woken session absorbed in `update_scene` without resetting its buffers; both tests (USDRenderCyclesTest.EditedStageRendersAsWithAFreshEngine and ProgressiveRenderTest.AFileReloadDuringAPass…) pin the two behaviours.
