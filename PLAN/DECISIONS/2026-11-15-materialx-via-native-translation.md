# 2026-11-15 — MaterialX through native translation

MaterialX, set aside on 2026-11-05, is reopened (user). It reaches Cycles and MoonRay through a Hydra scene index filter that translates each MaterialX network into the renderer's native nodes, never through generated OSL, GLSL or MSL: Cycles stays without OSL (`2026-11-05-no-cycles-osl`), and GLSL/MSL output is rasteriser code with lighting baked in. MoonRay renders MaterialX pattern nodes through DreamWorks' `materialx_shaders` (now public as `OpenMoonRay/materialx_shaders`), and Cycles matches MaterialX procedurals exactly through new SVM nodes in our Cycles fork. Storm keeps USD's own MaterialX path. A material that can't be fully translated renders flat magenta with a warning; a renderer's native network beats its MaterialX one. The work ships as F26 - MaterialX Rendering; MaterialX builder nodes follow as M446 - MaterialX Builder Nodes after F2 - Native Shader Networks lands.
