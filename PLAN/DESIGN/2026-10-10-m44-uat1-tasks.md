## What the code does today (why things move)

- **Spreading and shifting.** `KnobGuiContainerHelper` gives the field layout `Qt::AlignLeft`, and `KnobGuiValue::createWidget` puts everything in one `QHBoxLayout`: the spinboxes, the slider, the "4" button, then `KnobGuiColor::addExtraWidgets` (swatch, ▸, ⊕). The slider is the only widget that can grow.
  - Folded: the slider fills the row and pushes the buttons to the right edge.
  - Unfolded with the panel closed: `expandAllDimensions()` hides the slider. Nothing in the row can grow any more, so `AlignLeft` shrinks the row to its size hint. The four fields and the buttons collapse to the left. This is the "four fields shift left".
  - Unfolded with the panel open: the below-row column holds the `QTabWidget`, which expands, so the column is full width. The row container is stretched to fit, but none of its items can grow, so `QBoxLayout` hands the extra width out as equal gaps. This is the "spread evenly".
- **Auto-fold.** `KnobGuiValue::updateGUI` folds any knob whose channels are all equal, because `isAutoFoldDimensionsEnabled()` is always true for colour. Unfolding a neutral (1,1,1,1) gain therefore undoes itself on the next refresh unless something stops it.
- **Fold writes values.** `onDimensionSwitchClicked(false)` copies dim 0 into every other dim, so code must never call it just to tidy up the layout.
- **Lock keys.** The wheel's V/T locks depend on keyboard focus, which the wheel takes by stealing it on hover (`enterEvent` → `setFocus`), plus `_hovered`. A key pressed before the pointer reaches the wheel, or while focus is elsewhere, never arrives.
- **Slider modifiers.** `ScaleSliderQWidget` positions absolutely: a press jumps to the click and a drag follows the cursor. Ctrl zooms the scale 10× about the current value and Ctrl+Shift zooms it 100×. Both are driven by key events and need keyboard focus, which comes from hover focus-stealing. Shift alone does nothing. Alt+click resets to the default.
- **Offset temp/tint mismatch.** `sliderMapping` gives the Offset Temp and Tint sliders a range of ±50 "axis" units, where an axis unit is one unit of (a, b) chroma. The rate is 7e-4/px, so a full drag moves about 0.2, which is 0.2 % of the track.
