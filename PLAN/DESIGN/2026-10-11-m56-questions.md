# M56 - Visual And Menu Polish: open questions for the user (2026-10-11)

1. **Maximum node width before wrapping:**
   - (a) **Recommended:** 2× the default node width, so 160 logical px before DPI scaling, set as a constant.
   - (b) A different fixed pixel value.
   - (c) A Preferences setting. This touches `Engine/Settings.*` and makes P2.T1 bigger.
2. **Twin label text and row layout.**
   - Premult/Unpremult picker:
     - (a) **Recommended:** label it "Premult by" or "Unpremult by", per plugin, on its own row.
     - (b) A short "by" on the same row as the Layer picker, which is the plugin's intended layout.
     - (c) "(Un)premult by" on both, matching the host selector.
   - IDistort/STMap: U, V and Alpha each on their own row, labels aligned (**recommended**), or U and V side by side on one row.
3. **Toolbox tint:**
   - (a) **Recommended:** monochrome in the theme text colour. Colour already lives in the node graph, and this matches the direction you chose.
   - (b) Tint each group icon with its M24 category colour.
   - (c) Monochrome glyph with a small category-colour accent.
4. **"Use black & white toolbutton icons":**
   - (a) **Recommended:** remove it, with the old key silently ignored, as M55 did for auto-hide.
   - (b) Hide it and ignore its value.
5. **Which icons beyond the toolbox:**
   - (a) Toolbox plus M44's two icons only.
   - (b) **Recommended:** (a) plus the viewer toolbar, timeline and properties-panel chrome. Each area gets an approval sheet first.
   - (c) Everything, including roto, tracker, curve editor and dope sheet, with custom glyphs (enables P5.T4).
   - NativeNodes (33) and merge-operator icons (34): **recommended** out of scope, moved to a follow-up stub. Bundled OFX plugin icons stay PNG either way, so node icons would stay mixed.
6. **Licence route:**
   - (a) **Recommended:** stay GPL-2.0-or-later and use MIT/ISC sets only. With Lucide chosen this is effectively settled; it needs confirming. The record is `LICENSE-Lucide.txt` in About → Third-Party, a `README.md` line, and a per-glyph `SOURCES.txt`. Custom glyphs are GPL-2.0-or-later.
   - (b) Accept GPLv3-only distribution.
7. **How icons are drawn:**
   - (a) **Recommended:** render the SVGs at runtime through Qt6::Svg (a new link dependency), recoloured from the Preferences text colour, with a colour change applying after a restart.
   - (b) Pre-rasterise PNGs as M44 did. No new dependency, but no theming and fixed sharpness.
8. **Stylesheet direction:**
   - (a) **Recommended:** keep today's colours and change only spacing, padding and grouping. The spec is pitched as before/after mockups first.
   - (b) A full theme refresh with new Preferences colours.
   - Which reference look? **Recommended:** Nuke, which Natron already mimics. Houdini and Blender are the alternatives.
9. **"Menus" in the title:** the stub lists no menu item.
   - (a) **Recommended:** menu styling only (item padding, separators, icon column), done inside P6.T2.
   - (b) Menu restructuring as well. If so, name which menus.
10. **Grouping icons the icon page didn't settle:**
    - Toolsets: **recommended** Lucide `wrench`.
    - Misc and Other: **recommended** both use `puzzle`.
    - Also confirm pinning the latest Lucide release at implementation time.
11. **Milestone size:** keep M56 whole (**recommended**, the phases are independent), or split Phase 56.6 into its own milestone so wrap, labels and icons can ship first.
