# M69 elaboration: questions for the user (2026-10-11)

Open design questions from the M69 - Minor Cleanup elaboration. Each has a recommended default; the milestone briefs assume the default until answered. Split drafts: `2026-10-11-m69-split-drafts.md`.

| # | Question | Options | Recommended default |
|---|---|---|---|
| Q1 | Where does the global interactive toggle live, and on what shortcut? | (a) Viewer timeline-bar button + global shortcut + the existing preference; (b) Render menu action + shortcut; (c) preference only | **(a)**, Alt+U, bound to the existing "Refresh viewer only when editing is finished" setting |
| Q2 | App-level DPI | (a) Automatic only (already true: Qt6 devicePixelRatio + `TO_DPIX`); (b) add a UI-scale preference | **(a)**. Nothing to build; `QT_SCALE_FACTOR` is the escape hatch |
| Q3 | OFX plugins' own `hidpi`/`interactive` params (CornerPin, Ramp, Radial, Rectangle, Card3D, GodRays…) | (a) Host hides and drives them (M95.P2.T3); (b) leave them; (c) remove them in the openfx-supportext/misc/io/arena forks | **(a)**. One place, no fork PRs |
| Q4 | Paste onto a selected node | (a) Insert like node creation (re-route its outputs through the pasted node); (b) connect the input only | **(a)** |
| Q5 | Connection shortcuts | (a) Y = connect the others into the last-selected node; Shift+Y = the reverse; (b) other keys or rules | **(a)**, as in Nuke |
| Q6 | Pick-up mode: left-click on empty space while holding an input | (a) Cancel; (b) disconnect | **(a)**. Non-destructive; Escape and right-click also cancel |
| Q7 | Where does the picker's In/Out mode live, and is it saved? | (a) Viewer toolbar button, per viewer, session only; (b) a Preference; (c) a modifier on the pick click | **(a)**, default In |
| Q8 | In mode with several inputs | (a) The viewed node's preferred/main input (B on Merge); (b) input 0; (c) a selectable index | **(a)**. Fall back to Out when there is no input |
| Q9 | Roto multi-feather rule | (a) Same signed distance along each point's own normal; (b) same vector for all; (c) scale proportionally | **(a)**, as the scout recommended |
| Q10 | Joining broken tangents | (a) Mean of the two angles; (b) keep the left slope; (c) keep the right slope | **(a)** |
| Q11 | Footer order below the line | (Un)premult by → Clamp black → Clamp white → mask channel → Invert mask → Mix? | **Yes** |
| Q12 | New Keyer's key signal and inputs | (a) Luminance or Colour (key colour), host mask/mix only, no Bg/InM/OutM; (b) also keep the InM/OutM garbage/core mattes; (c) luminance only | **(a)** |
| Q13 | Keyer identity and old projects | (a) Same ID, major 3, clean break (old knobs dropped); (b) new ID, keeping the old Keyer hidden for old projects; (c) migrate old values onto A–D | **(a)**, matching M67's clean-break rule |
| Q14 | Does ChromaKeyer share the new matte stage? | (a) No, leave it as is; (b) yes, alpha-only too (M95.P4.T4) | **(a)**. ChromaKeyer's despill/composite are its reason to exist; the helper is shared later if wanted |
| Q15 | Curve handle "lengthen/shorten" | (a) Split to M96 after M93 (M69 does break/join + visual drag); (b) do weights in M69 now | **(a)**. Weights change the keyframe archive that M93 is reshaping |
| Q16 | Accept the split into M69 / M95 / M96? | Yes / keep one milestone | **Yes** |
