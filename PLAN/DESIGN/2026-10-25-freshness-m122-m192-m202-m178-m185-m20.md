## M185 - Variable Warps
- ITransform and ICornerPin are `OpKind::Custom` ops (like `IDistort` and `STMap`), not I-variants of Transform/CornerPin's `OpKind::Resample` classes, which take one matrix per image and read no Aux input. `Resampler.h` `resampleRowFromCoords` and `coordJacobians` (:340-420) are the base for per-pixel Jacobians.
- Transform has two registrations (Transform, TransformMasked); the I-variant has the mask built in.
- Map convention from M184: `Engine/Nodes/Filter/MapInput.h` (`kMapInputSpec`, `mapChannel/mapInvert/mapResponse/mapGamma`); `NATRON_I_VARIANT` in `.reg.inc` (`Filter/IBlur.reg.inc`). Map input goes after Mask, as in IBlur. No project compatibility, so input order is free.
- Main's M132 changed STMap (`uvAlpha`, 34-word `WarpGpuParams`, `stmap.slang` shared with IDistort); rebase M185's branch onto main (or onto a rebased M184) before touching STMap/IDistort GPU code.
- Paths: docs `Engine/Nodes/Transform/docs/`; `Engine/Nodes/Image/Resampler.h`, `Engine/Gpu/Kernels/coordmap.slang`, `WarpGpu.h` (`recordWarpGpu`); tests `NativeIDistort_Test.cpp`, `NativeSTMap_Test.cpp`, `CoordMapGpu_Test.cpp`, `ResamplerCoordMap_Test.cpp`.
