# HSVKeyer design (M122 - Native Colour Utilities, UAT round 1)

User decisions (2026-10-26): models HSV / HSL / OkLCh; pick recentres keeping widths; hue fades out at low chroma; output Alpha / Premultiplied / Matte.

## Controls
`sourceColor` (3-dim KnobColor, viewer picker), `colorModel` (HSV / HSL / OkLCh), trapezoids `hueRange`, `satRange`, `lumaRange` (4-dim KnobDouble: outerLow, innerLow, innerHigh, outerHigh), toggles `useHue`, `useSat`, `useLuma` (on), `invert`, `outputMode` (Alpha default / Premultiplied / Matte), a Recentre button.

## Colour models
Hue in turns [0,1), 0 at zero chroma. Switching model recentres the ranges on the source colour.
- HSV (`ColorMath.h:526`): hex hue (`ColorMath.h:421`), s = (max−min)/max, V = max.
- HSL (`ColorMath.h:554`): s = (max−min)/(L ≤ ½ ? max+min : 2−max−min), L = (max+min)/2. Unclamped for HDR.
- OkLCh: working RGB → XYZ (`workingToXYZ`, `ColorMath.h:219`) → Bradford to D65 → LMS (M1) → signed cbrt → Lab (M2); L = third axis, C = √(a²+b²) (display 0–0.4), h = atan2(b,a)/2π mod 1. Fuse working→LMS into one 3×3 at bake (as `Colorspace.cpp:154-155`). Float copy of the OkLab maths in Engine (Gui has a double one, `Gui/DisplayLegendColour.h:44-63`).
  - M1 = [[0.8189330101, 0.3618667424, −0.1288597137], [0.0329845436, 0.9293118715, 0.0361456387], [0.0482003018, 0.2643662691, 0.6338517070]]
  - M2 = [[0.2104542553, 0.7936177850, −0.0040720468], [1.9779984951, −2.4285922050, 0.4505937099], [0.0259040371, 0.7827717662, −0.8086757660]]
- Hue key is weighted by a smooth ramp on chroma near 0, so greys never match a hue range.

## Trapezoid knob and widget
- Plain 4-dim KnobDouble (animation, expressions, serialization, curve editor for free). Bake tolerates disorder: sat/luma push values up (`s[i] = max(s[i], s[i-1])`), hue measures up the circle mod 1 (`HueCurves::hueTrapezoid`, `HueCurves.h:217`).
- Not a new knob type: `KnobGuiFactory::createGuiForKnob` dispatches on `typeName()` (`Gui/KnobGuiFactory.cpp:120-137`) and `KnobDouble::typeName` is FINAL. Add `KnobDouble::setRangeWidget(role, sourceColourKnob, modelKnob)`, checked before the typeName lookup, building `Gui/KnobGuiTrapezoid.{h,cpp}`; embed the strip as `KnobGuiParametric::createWidget` does (`Gui/KnobGuiParametric.cpp:115-182`); edits go through KnobGuiValue's per-dimension path for undo.
- Strip: trapezoid polygon over a gradient (hue spectrum centred on the plateau so a range across red is never split; sat: grey → source hue; luma: black → white, extending past 1), working→display through `makeDisplayConverter` (`Gui/KnobGuiColor.cpp:98`). Four handles clamped between neighbours (along the circle for hue); plateau drag moves all four; shift-drag on an inner handle moves its outer partner. Four spinboxes below. Repaints on source/model change; may draw the viewer hover sample via `setInteractColourPicker` (`ViewerGL.cpp:3043-3060`).
- Python: the `PyNode.cpp:458-470` switch covers 1–3 dims only; add a generic or 4D fallback.

## Picking
Swatch toggle (`ColorPickerLabel`, `KnobGuiColor.cpp:335-363`) → `ProjectGui::setPickersColor` (`ProjectGui.cpp:294-309`), sampling the node's input (`resolvePickOutput`, `ViewerGL.cpp:124-129`). Recentre in `knobChanged` as `HSVTool::knobChanged` does (`HSVTool.cpp:981-1034`): skip load / time change / slave refresh / restore default; one undo step via `setMultipleParamsEditLevel`; shift each trapezoid so its plateau centre lands on the picked component, keeping its offsets. Recentring writes at the current time only.

## Combination and output
key = Π over enabled components (none enabled → 1); `invert`. Output: Alpha (RGB passes), Premultiplied (rgb·key), Matte (rgb = key), as Keyer's `show` (`Keyer.cpp:938-942`) minus suppression; pipeline layers write RGB too.

## GPU and cost
Stays an analytic IPixelOp. `hue.slang:518-560` HueKeyerOp → HSVKeyerOp (flags: invert, 3 enables, 2 model bits, 2 output bits; three float4 trapezoids; 9-float working→LMS matrix); rename in `hue.cmake:3`. 1e-5 tolerance. Re-measure the cost seed.
