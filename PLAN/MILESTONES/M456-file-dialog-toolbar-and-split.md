# M456 - File Dialog Toolbar And Split

Two user requests (2026-11-16) for the file dialog (`Gui/SequenceFileDialog.cpp`): a top row laid out like other file browsers, and a way to load one contiguous part of a sequence with gaps (frames 10-20 and 30-40 load as either range). Today the top row is "Look in" combo, a stretch, then back/forward/up/new folder pushed right (~273-327); sequences with gaps are one item, `plate.####.exr ( 10-20 30-40 )` (`FileGathererThread::gatheringKernel`, `Engine/FileSystemModel.cpp`; `generateUserFriendlySequencePatternFromValidPattern`, `libs/SequenceParsing`), and only the pattern reaches the Read (`selectedFiles()`, ~1712-1737; `Gui/KnobGuiFile.cpp:176`), which then spans 10-40 and errors on the gap by default. Layout chosen by the user from mockups (option A; mockup script `build/mockups/filedialog/mock.py` on the dev host).

## Scope

**In:**
- Row 1: back, forward, up, home, separator, the path combo stretching to fill, New Folder (icon and text), separator, list/detail view toggles.
- Row 2: "Sequences" checkbox (replaces the bottom row's Sequence/File combo), "Split on gaps" checkbox, and "Show hidden" right-aligned.
- Split on gaps: each contiguous run of frames is its own item, `plate.####.exr 10-20`; any missing frame splits.
- Picking a chunk loads the pattern and sets the Read's first/last frame to the chunk.
- The three toggles are remembered per user; Split on gaps starts off the first time.
- Right-click on a sequence item offers "Split sequence" / "Join sequence" for that item alone.

**Out:**
- A breadcrumb path (option C) — none.
- A range syntax in the file path — none.
- Changes to how Read handles missing frames — none.

**Edge cases:**
- Save dialogs (Write): same rows; Split on gaps is disabled there.
- Several chunks selected: each loads as its own Read where multi-selection already creates several Reads; otherwise the first chunk is used.
- A single-frame chunk shows `plate.####.exr 25`, and the Read's range is 25-25.
- Sequences off: Split on gaps is disabled.
- Dialog width: the rows fit a 1920x1080 screen at scale 1.
