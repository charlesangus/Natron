# Rewrite core nodes natively rather than patch OpenFX per-node memory

2026-10-03. M62.P5.T1 measured ~0.65 MB of heap per idle node on an OFX Grade chain (518 KB useful + 135 KB malloc overhead), of which 75–80% is OpenFX-specific: param instances deep-copying descriptor property sets (250 KB), clip and effect-instance property sets (56 KB), interact descriptors (16 KB), and OFX→knob glue (~67 KB). Native nodes (M17 framework) pay only the generic knob cost, estimated at 100–150 KB. Asked whether to take the four local fixes (copy-on-write property sets in the openfx fork, lazy interact descriptors, lazy dynamic-property connections, lazy curves/pages) into M62, the user chose none now: they are parked in M31 Phase 31.2 as speculative, and a new stub milestone M67 rewrites the core 2D nodes as native nodes instead, starting with a native-vs-OFX chain benchmark (moved out of M62.P6.T1). Rationale: the fixes treat a cost that disappears for native nodes, and native nodes also remove the ABI boundary that the HD profiles show in host/plugin copying.
