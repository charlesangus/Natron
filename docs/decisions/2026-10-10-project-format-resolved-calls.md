# Project format: resolved calls

M16 - Project Format Redesign replaces the boost XML `.ntp` with a `.ntpz` bundle, a stored-only zip of YAML documents plus binary column tables (`mimetype`, `manifest.yaml`, `project.yaml`, `blobs/**`), and makes a clean break: old XML `.ntp`, `.nps` and `.nl` files are not imported and give an old-format message. Connections are sibling-relative: a group's nodes nest under `children:`, and a consumer's `inputs:` names a sibling's script name. Presets keep the `.nps` extension as a plain YAML document, because a preset is one small text file and not a container. Heavy roto and tracker data is stored as flat, typed, named column tables with a 64-byte header and 64-byte-aligned columns; these map in place with no codegen, and readers match columns by name so tables can evolve. YAML goes through yaml-cpp (private to `NatronSerialization`) and the zip container is the in-house stored-only `ZipStore`, because no library aligns member data. The 2026-10-23 user decision dropped `gui.yaml`: node position, size and colours are per-node data in `project.yaml`, pane layout is app-level in `.nl` files, and viewer state, selection and open panels are not saved. boost.serialization stays only for the disk-cache table of contents.
