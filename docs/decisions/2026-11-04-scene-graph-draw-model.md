Scene graph display is redesigned around three independent states: twirl (per panel, browsing only), draw state (per viewer: BBox, Children, Full, Full + Load, Hidden; saved with the viewer) and load set (per stage; a payload loads only through an intentional act on a row). This replaces M231 - Scene Graph Panel's folding, where tree state was scene state. Draw states and graph policy shape viewers only: USDRender and USDWrite always get the whole scene, and display state never enters a USD layer. Patterns match what their evaluator has loaded (deferred matching). The mechanism that applies draw states to Hydra is settled by M327 - Heavy Scene Spike. All user decisions from a grilling session; full design in `PLAN/DESIGN/2026-11-04-scene-graph-design.md`.
