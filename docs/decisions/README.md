# Decision records

Published copies of the project-wide decisions taken while building this fork.

These are a **mirror, not the source**. Each file is copied verbatim from the
project plan, which lives on the orphan `plan` branch (checked out at `.plan/`)
and is never merged into `main`. Editing a file here changes nothing; amend or
supersede the decision on the plan branch and the next milestone republishes it.

They are published because a decision a future reader of *this code* needs
should be readable from the code, not only from a branch they may never check
out. Milestone-scoped execution detail is deliberately not published here.
